Course Description

This course covers fundamental concepts, principles, and practical techniques for securing computer networks. It examines both traditional and emerging threats, along with defense mechanisms deployed at Internet scale. Major topics include Internet protocol security, web security, mobile malware analysis, network monitoring and anomaly detection, cryptography fundamentals, cloud security, and advanced topics such as 5G and satellite network security. Students will gain hands-on experience with security tools and techniques, develop practical skills through applied exercises, and be inspired to pursue advanced projects and research in network security.
